## 폼이 걸러내는 것

| 장치 | 하는 일 |
|---|---|
| 번호 형식 검증 | `01X-XXXX-XXXX` 가 아니면 제출 자체가 안 됨 (페이지·서버 양쪽에서 검사) |
| 자료를 **문자로만** 발송 | 제출 직후 링크를 주지 않음. 가짜 번호를 넣으면 아무것도 못 받음 |
| 봇 차단 | 사람 눈에 안 보이는 칸이 채워지면 조용히 버림 |
| 같은 IP 속도 제한 | 한 시간에 8건까지 |
| 출처 제한 | 우리 사이트가 아닌 곳에서 보낸 신청은 거부 |
| 같은 번호 중복 | 새 내용으로 덮어씀. 명단이 지저분해지지 않음 |

## 동의 구조 — 왜 이렇게 나눴나

| 구분 | 내용 | 필수 여부 | 근거 |
|---|---|---|---|
| ① 개인정보 수집·이용 | 이름·학년·학교·번호 / 자료 발송 및 문의 응대 / 1년 보유 | **필수** | 보낼 방법이 없으면 신청 자체가 성립하지 않음 |
| ② 광고성 정보 수신 | 설명회·특강 안내 / 월 2회 이내 | **선택** | 「개인정보 보호법」 제22조 — 선택 동의를 필수로 강제할 수 없음 |

②를 필수로 묶으면 과태료 대상입니다. 대신 ①의 목적에 **"자료 발송 및 문의 응대"**를
넣어 두었으므로, 신청한 자료를 보내고 그에 대해 연락하는 것은 ② 없이도 됩니다.

**삭제 요청이 오면** 말씀만 주세요. 해당 번호만 지웁니다.

## 유입경로 자동 추적

각 채널에 뿌리는 링크 끝에 `?src=` 를 붙이면 폼에 자동으로 채워집니다.
학생이 고르지 않아도 되니 정확도가 올라갑니다.

| 채널 | 뿌릴 링크 |
|---|---|
| 유튜브 | `https://jayu0422-blip.github.io/daol105-susi/hs12/?src=youtube` |
| 인스타그램 | `.../hs12/?src=instagram` |
| 네이버 블로그 | `.../hs12/?src=naver` |
| 카카오톡 | `.../hs12/?src=kakao` |
| 전단지 QR | `.../hs12/?src=print` |

`utm_source=` 도 똑같이 인식합니다.
