**먼저 말씀해 주세요.** 선택 동의 항목을 다시 넣어드리겠습니다.

## 폼이 걸러내는 것

| 장치 | 하는 일 |
|---|---|
| 번호 형식 검증 | `01X-XXXX-XXXX` 가 아니면 제출 자체가 안 됨 (페이지·서버 양쪽에서 검사) |
| 자료를 **문자로만** 발송 | 제출 직후 링크를 주지 않음. 가짜 번호를 넣으면 아무것도 못 받음 |
| 봇 차단 | 사람 눈에 안 보이는 칸이 채워지면 조용히 버림 |
| 같은 IP 속도 제한 | 한 시간에 8건까지 |
| 출처 제한 | 우리 사이트가 아닌 곳에서 보낸 신청은 거부 |
| 같은 번호 중복 | 새 내용으로 덮어씀. 명단이 지저분해지지 않음 |

## 동의 — 필수 하나만 받습니다

체크박스는 **하나**입니다. 체크하지 않으면 제출이 막힙니다.

```
[필수] 개인정보 수집·이용 및 입시 자료 수신 동의
  수집항목  이름 · 학년 · 학교 · 휴대폰 (보호자 번호는 선택)
  이용목적  조회 결과 상세 제공 및 입시 자료 제공
           (입시 설명회 영상, 기출 분석 자료, 모의고사·수시 일정 안내)
  보유기간  수집일로부터 6개월
  광고성 정보(수강 안내·모집·할인)는 보내지 않습니다.
```

### 반드시 지켜야 하는 선

이 동의로 보낼 수 있는 것은 **정보성 입시 자료까지**입니다.

| 보내도 되는 것 | 보내면 안 되는 것 |
|---|---|
| 조회 결과 열람 링크 | 수강생 모집 안내 |
| 입시 설명회 영상 | 할인·혜택 안내 |
| 기출 분석 자료 | 개강 · 특강 모집 광고 |
| 모의고사 · 수시 일정 안내 | 그 밖 영리목적 광고 |

오른쪽을 보내려면 **광고성 정보 수신 동의를 따로 받아야 합니다**
(정보통신망법 제50조). 지금 폼에는 그 항목이 없으므로 보내시면 안 됩니다.
나중에 보내고 싶으시면 말씀해 주세요. 선택 항목을 다시 넣겠습니다.

**삭제 요청이 오면** 말씀만 주세요. 해당 번호만 지웁니다.

## 유입경로 자동 추적

각 채널에 뿌리는 링크 끝에 `?src=` 를 붙이면 폼에 자동으로 채워집니다.
학생이 고르지 않아도 되니 정확도가 올라갑니다.

| 채널 | 뿌릴 링크 |
|---|---|
| 유튜브 | `https://jayu0422-blip.github.io/daol105-susi/hs12/?src=youtube` |
| 인스타그램 | `.../hs12/?src=instagram` |
| 네이버 블로그 | `.../hs12/?src=naver` |
| 카카오톡 | `.../hs12/?src=kakao` |
| 전단지 QR | `.../hs12/?src=print` |

`utm_source=` 도 똑같이 인식합니다.
