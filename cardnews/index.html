3. 올리는 순서

  1. 사진 10장을 순서대로 저장합니다. 각 카드 아래 「저장」을 누르세요.
  2. 인스타 → 새 게시물 → 여러 항목 선택 → 10장을 번호 순서대로 고릅니다. 순서가 섞이면 이야기가 끊깁니다.
  3. 자르기에서 4:5(세로)를 고릅니다. 정사각형으로 두면 위아래가 잘립니다.
  4. 위 캡션 복사를 눌러 붙여넣고, 이어서 태그 복사를 붙입니다.
  5. 고급 설정 → 대체 텍스트 편집. 각 카드 밑의 회색 글상자를 눌러 복사해 넣습니다. 인스타 검색에 걸리는데 거의 아무도 안 씁니다.
  6. 위치 추가 → 하남시 (다음 게시물은 미사강변도시, 그다음은 풍산동으로 돌립니다).
  7. 게시 후 스토리로 공유하고 링크 스티커를 붙이세요. 이게 있어야 카드뉴스에서 바로 랜딩으로 넘어갑니다.
  8. 첫 댓글에 지역 태그를 한 번 더 답니다.

올리는 시간은 밤 9~10시. 하남 학부모가 아이 픽업 끝내고 폰을 보는 시간대입니다.
