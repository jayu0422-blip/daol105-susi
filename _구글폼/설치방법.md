전체 3분. 원장님이 하실 일은 **1단계와 3단계 두 개뿐**입니다.

---

## 1단계 · 폼 만들기 (2분)

1. https://script.google.com 접속 → **새 프로젝트**
2. 편집기 안의 기존 내용을 지우고 [`폼생성.gs`](폼생성.gs) 전체를 붙여넣기
3. 위쪽 함수 선택창에서 **폼만들기** 선택 → **실행**
4. 권한 승인
   - "이 앱은 확인되지 않았습니다" → **고급** → **다올105...(으)로 이동** → **허용**
   - 본인 계정이 만드는 스크립트라 정상입니다
5. 아래 **실행 로그**에 주소 4개가 찍힙니다. 그중 **①번 주소를 저에게 주세요.**

```
① 학생이 여는 주소 (페이지 버튼에 연결)
   https://docs.google.com/forms/d/e/......./viewform
② 응답 스프레드시트
③ 폼 편집 주소
④ 프리필 주소
```

①번 주소를 주시면 `hs12/index.html`의 이 한 줄만 채우고 배포합니다.

```javascript
var FORM_URL='';   // ← 여기
```

- **비어 있는 동안에는** 지금처럼 "곧 열립니다" 안내가 나갑니다. 깨지지 않습니다.
- ④번 주소까지 주시면 **유입경로·학년이 자동으로 채워진** 상태로 폼이 열립니다.
  (학생이 유튜브 링크로 들어오면 "유튜브"가 이미 선택되어 있음)

## 3단계 · 문자 보내기 (신청이 쌓인 뒤)

1. `script.google.com`의 같은 프로젝트에서 `발송명단만들기` 함수 안의 이 줄에
   **②번 응답 스프레드시트 주소**를 붙여넣습니다.

```javascript
var ss = SpreadsheetApp.openByUrl(
  '여기에_응답_스프레드시트_주소를_붙여넣으세요'
);
```

2. **발송명단만들기** 실행 → 내 드라이브에 `발송명단.csv` 생성
3. 문자114에 업로드 → 아래 문안으로 발송
4. 보낸 사람은 응답 시트의 **발송** 열에 `O`를 적어두면 다음 회차에서 빠집니다

```

다올105 (제 하남 298호) 031-794-8158
```

> 이 문자는 **신청자가 직접 요청한 자료의 전달**이므로 정보통신망법 제50조의

> 반대로 **설명회·특강 안내**를 보낼 때는 폼에서 [선택] 동의에 체크한 사람에게만,
> 제목 앞에 `(광고)`, 본문 끝에 무료 수신거부 방법을 반드시 넣어야 합니다.

## 폼에 들어가는 동의 구조

| 구분 | 내용 | 필수 여부 | 근거 |
|---|---|---|---|
| ① 개인정보 수집·이용 | 이름·학년·학교·번호 / 자료 발송 목적 / 1년 보유 | **필수** | 자료를 보낼 방법이 없으면 신청 자체가 성립하지 않음 |
| ② 광고성 정보 수신 | 설명회·특강 안내 / 월 2회 이내 | **선택** | 「개인정보 보호법」 제22조 — 선택 동의를 필수로 강제할 수 없음 |

②를 필수로 만들면 과태료 대상입니다. 대신 ①의 목적에 **"자료 발송 및 문의 응대"**를
넣어 두었기 때문에, 신청한 자료를 보내고 그에 대해 연락하는 것은 ② 없이도 가능합니다.

## 왜 이 방식인가 — 진짜 번호를 받는 구조

| 장치 | 하는 일 |
|---|---|
| 번호 형식 검증 | `01X-XXXX-XXXX` 가 아니면 폼 제출 자체가 막힘 |
| 자료를 **문자로만** 발송 | 제출 직후 화면에 링크를 주지 않음. 가짜 번호를 넣으면 아무것도 못 받음 |
| 제출 후 안내 문구 | "번호를 잘못 적으셨다면 다시 신청해 주세요" — 오타 자진 정정 유도 |
| 무료 조회는 그대로 개방 | 번호를 안 주면 못 쓰는 게 아니라, **주면 더 받는** 구조. 반감이 적음 |

CTA 문구도 같은 원리로 썼습니다.

> **여기까지가 무료로 보여드릴 수 있는 전부입니다**
> 나머지는 문자로 보내드립니다. **번호를 받는 이유는 그것 하나입니다.**
>
> 받는 번호로만 보냅니다. 번호가 틀리면 자료가 가지 않습니다.
> **설명회·특강 안내 문자는 따로 동의하셔야 보냅니다.** 원치 않으시면 안 보냅니다.
> 삭제를 원하시면 031-794-8158로 말씀만 주세요. 바로 지웁니다.

받는 이유를 숨기지 않고 먼저 말하는 쪽이 전환율이 높습니다.
"이벤트 응모" 같은 우회 문구는 개인정보 보호법 제22조의 **목적 명확성**에도 걸립니다.

## 유입경로 자동 추적

각 채널에 뿌리는 링크 끝에 `?src=` 를 붙이면 폼에 자동으로 채워집니다.

| 채널 | 링크 |
|---|---|
| 유튜브 | `.../hs12/?src=youtube` |
| 인스타그램 | `.../hs12/?src=instagram` |
| 네이버 블로그 | `.../hs12/?src=naver` |
| 카카오톡 | `.../hs12/?src=kakao` |
| 전단지 QR | `.../hs12/?src=print` |

`utm_source=` 도 똑같이 인식합니다.
